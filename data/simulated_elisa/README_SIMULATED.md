# SIMULATED ELISA dataset — not experimental data

Every file in this directory was generated by `src/simulate_elisa.py`. No ELISA was
run. Optical densities are drawn from a defined four-parameter logistic curve with a
stochastic noise model under a fixed seed. No instrument, kit, lot number, operator, or
storage location is represented, because none exists.

Purpose: development and testing of an ELISA processing pipeline (plate parsing, 4PL
fitting, back-calculation, QC flagging, LLOQ/ULOQ handling) against known ground truth.

| File | Content |
|---|---|
| `SIMULATED_elisa_plate_NN_OD.csv` | 8 × 12 plate-format OD grid, one per plate |
| `SIMULATED_elisa_plate_NN_layout.csv` | well → role, sample id, nominal standard concentration |
| `SIMULATED_elisa_long.csv` | one row per well across all plates; the ingestion table |
| `SIMULATED_elisa_ground_truth.csv` | true concentration of every unknown, QC, and blank |
| `SIMULATED_elisa_parameters.json` | seed, 4PL parameters, noise model, layout description |

All CSVs open with `# SIMULATED DATA` comment lines; read them with `comment='#'`.
Regenerate with `python3 src/simulate_elisa.py` (options: `--plates`, `--seed`, `--cv`).
